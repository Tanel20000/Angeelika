# Angeelika — AI-Powered Phone Security

## Overview

Angeelika is a prototype exploring how artificial intelligence can
help identify potentially fraudulent phone conversations and provide
an additional layer of protection for people who may be vulnerable
to telephone scams.

The project combines speech processing, AI-based analysis and
telephony infrastructure in a working prototype.

## Goals

- Explore AI-assisted detection of suspicious phone conversations.
- Process speech and analyze conversational context.
- Integrate AI services with a telephony system.
- Investigate practical approaches to protecting users from phone scams.

## Technology

- Python
- Linux and Ubuntu Server
- Asterisk telephony infrastructure
- SIP-based telephony
- Speech-to-text processing
- Large language models and AI APIs
- Telegram bot integration for testing and notifications

## Prototype status

The project has been developed and tested as an independent prototype.
Its components explore speech processing, AI-based risk assessment
and integration with telephony infrastructure.

This is an ongoing development project. Detection quality, false
positives, reliability and practical deployment requirements require
continued testing and improvement.

## My work

The project involves hands-on work with Python services, Linux server
administration, AI API integration, speech processing, telephony
integration, troubleshooting and iterative testing.

## Architecture

At a high level, the prototype explores the following workflow:

1. A phone call enters the telephony infrastructure.
2. Audio is made available to a speech-processing component.
3. Speech is transcribed and analyzed for potential scam indicators.
4. The system can generate a risk assessment.
5. A notification or report can be provided through a separate interface.

The exact implementation details are intentionally not published.

## Security and privacy

This repository is a public project overview, not the production
source code. Server credentials, API keys, private configuration,
call recordings, personal data and internal detection logic are not
included.

## Disclaimer

Angeelika is an experimental prototype, not a guarantee that every
fraudulent call will be detected. AI-generated risk assessments may
be incorrect and require careful evaluation.
